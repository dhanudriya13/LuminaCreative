# Prompt 03 — Core Pages and Static Content

Implement the website pages using `/docs/UI_UX_SPEC.md` and `/docs/CONTENT_GUIDELINES.md`.

Required pages:
- Homepage.
- Services index.
- Four service detail pages.
- Work/portfolio index.
- Project case-study template.
- About.
- Contact.
- Privacy policy and terms placeholders only if owner-approved legal copy is supplied.

Use static, typed, repository-managed content. Do not add a CMS or admin dashboard.

Bilingual requirements:
- English and Indonesian routes/content.
- Localized navigation, labels, CTAs, metadata and form copy.
- Correct document language and hreflang.
- Language switching should preserve the equivalent route when available.

Portfolio requirements:
- Every project has classification: client, internal, research or demo.
- Do not fabricate client names, logos, results, testimonials or project metrics.
- If real content is unavailable, create clearly marked content TODOs rather than invented facts.
- Do not publish placeholder content as factual production copy.

Conversion:
- Clear primary CTA.
- Relevant service CTA.
- Contact page accessible from every page.
- WhatsApp contact uses centralized configuration.

Run route, responsive, localization, accessibility, lint, type-check and build checks. Report all content still needed from the owner.
