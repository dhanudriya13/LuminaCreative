# Prompt 02 — Foundation and Design System

Use the completed repository audit and approved specifications.

Implement the shared foundation only:

- Centralized site configuration.
- English/Indonesian locale strategy and language switcher.
- Global layouts and page shell.
- Responsive navigation and footer.
- Design tokens for colors, typography, spacing, radii and breakpoints.
- Reusable buttons, links, cards, section headings and form primitives.
- Accessible focus, hover, active, disabled and loading states.
- Reduced-motion support.
- Shared metadata helpers if appropriate.

Rules:
- Keep the existing framework and styling approach.
- Confirm existing logo/brand assets before applying proposed colors.
- Avoid introducing dependencies unless justified.
- Do not create fake content or claims.
- Test desktop and mobile navigation in both locales.

Run the repository's lint, type-check and build commands. Report files changed, tests and any deviations from the spec.
